An AI assistant says, "I can't help with that." But did it already start using tools?

AgentHarm asks whether an agent both refuses a malicious request and avoids carrying it out.

This is not an attacker hiding instructions in a webpage. Here, the user directly asks for harm.

The benchmark comes from Gray Swan AI and the UK AI Security Institute.

It contains one hundred and ten base tasks across eleven harm categories, expanded into four hundred and forty variants.

Imagine a harmless event assistant: find a venue, check contacts, prepare invitations. Each step needs information from the last.

AgentHarm tests that kind of connected tool use, but with harmful objectives.

The tools are synthetic. No real emails or payments happen.

Human-written checks score the actions, with narrow model judgments where meaning matters. Refusals are measured separately.

In the paper's public test, Claude three point five Sonnet's average harm score rose from thirteen point five to sixty-eight point seven percent with a jailbreak template.

That's partial-credit task scoring, not the percentage of real-world attacks completed.

The weakness? English-only prompts, no user follow-ups, and simplified tools. This tests basic agent skills, not unrestricted autonomy.

The lesson: check what an agent does, not just what it says.
